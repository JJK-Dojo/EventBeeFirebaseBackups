# **App Name**: LocalLooms

## Core Features:

- User Authentication: Secure user authentication using Gmail and phone number verification through Firebase Authentication.
- Event Posting: Allow users to post local events with details such as date, time, description, and duration (up to 30 days).
- Location Integration: Integrate Google Maps for event location selection and display.
- Geo-Location Search: Enable users to search for events within a specified distance from a selected location. Implement a tool that uses the selected criteria for information extraction.
- Event Listing: Display events in a list or map view, sorted by proximity or date.
- Event Details: Provide a detailed view for each event, including all relevant information and a map for navigation.
- Firebase Integration: Use Firebase Firestore as a NoSQL database to store event and user data, taking advantage of its real-time capabilities.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to convey trust and technology.
- Background color: Light gray (#F5F5F5) for a clean, modern look.
- Accent color: A bright green (#90EE90) to highlight important actions.
- Body and headline font: 'PT Sans' for a modern yet warm feel; readable for both headings and body text.
- Use clean, modern icons to represent event categories and actions.
- Maintain a clean, card-based layout to display events and information in a structured manner.
- Subtle transitions and animations for a smooth user experience.
